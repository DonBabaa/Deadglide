# Recorded sounds (optional)

The game synthesizes all of its sounds, so this folder can stay empty.

If you put an audio file here, it replaces the synthesized sound with the same name:

| File | Replaces |
|---|---|
| `sniper.mp3` | the sniper rifle shot |

`.mp3`, `.ogg`, `.wav` and `.m4a` all work. Restart `npm run dev` after adding a file.
Only use recordings you have the right to distribute, since they ship with the game.
